## 1. Mô tả hệ thống
Hệ thống Quản lý Nhân sự giúp xem, thêm, sửa, xóa và tìm kiếm hồ sơ nhân viên trực tuyến.

## 2. Công nghệ sử dụng
* **Frontend**: React.js[cite: 1]
* **Backend**: Node.js, Express[cite: 1]
* **Database**: MongoDB Atlas[cite: 1]
* **Containerization**: Docker, Docker Hub[cite: 1]
* **Deployment**: Render[cite: 1]

## 3. Hướng dẫn chạy ở môi trường phát triển (Local)
### Backend:
cd backend
npm install
npm start

### Frontend:
cd frontend
npm install
npm start
